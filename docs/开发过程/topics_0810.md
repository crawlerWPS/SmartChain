The assistant explained that @RequiredArgsConstructor generates constructors for final and @NonNull fields (used for Spring constructor injection in Service/Controller), @Data is for data classes (generates getters/setters/toString/equals/hashCode + @RequiredArgsConstructor), and @Slf4j provides a logger. They confirmed no conflicts but noted @Data includes @RequiredArgsConstructor and @EqualsAndHashCode. The user reported IDE issues with unrecognized annotations; the assistant diagnosed it as IDE cache problems and provided solutions (reload window, refresh Maven, clean Java workspace, check Lombok plugin).
