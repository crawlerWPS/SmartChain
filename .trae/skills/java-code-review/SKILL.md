# Java代码评审技能
## 触发条件
1. 用户提交Java代码、Mapper XML，要求代码审查、找bug、优化
2. SOLO代码生成完成后自动调用本技能做质检
3. 关键词：代码评审、查漏洞、优化、规范检查、阿里规范

## 评审维度
1. 编码规范：命名、注释、缩进、常量定义、魔法值
2. 安全漏洞：SQL注入、XSS、越权、明文密码、未校验入参
3. 性能隐患：无索引SQL、循环查库、未使用缓存、大对象内存泄漏
4. 业务风险：事务失效、未判空、异常未捕获、分页无上限
5. 工程规范：依赖冲突、冗余import、未使用变量、重复代码

## 输出格式
1. 风险等级：P0阻塞/ P1优化/ P2建议
2. 问题代码片段
3. 错误原因
4. 修正后标准代码
5. 整体优化总结
